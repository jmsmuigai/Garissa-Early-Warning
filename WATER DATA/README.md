# Water and WASH data

These files feed the water-point and WASH layers of the early-warning maps.

**Privacy:** personal data has been removed before publication. Enumerator names and phone numbers, facility in-charge and head-teacher names and phone numbers, water-point contact persons, KoboToolbox usernames, device and submission IDs, and timestamps were dropped. What remains is facility-level information (location, infrastructure, service levels).

Raw survey exports that contain personal data must never be committed to this repository. Keep them in access-controlled storage and run them through the anonymisation step first.
